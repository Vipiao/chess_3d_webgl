Online, so you don't need to host local:
https://fjellheim.org/markus/game/chess/

last updated version 3.0.0.

1. Start python server.
	After cloning, navigate in the terminal to the top folder (the one with the readme) and run "python -m http.server".
	For this to work, you must have python installed and in your environment path.
2. Go to http://localhost:8000/
3. Enjoy.
